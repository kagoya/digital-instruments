# Digital Instruments

JavaScriptとWeb Audio APIで演奏できるデジタル楽器です。外部ライブラリや音声ファイルは不要です。

## 演奏する

https://kagoya.github.io/digital-instruments/

- ピアノ、トランペット、フルート、ギターの音色と見た目を切り替え
- マウス、タッチ、キーボードで演奏
- 和音、音量調整、サステイン
- 楽器を選んだ直後もキーボードで演奏可能

キーボードの A S D F G H J はドレミファソラシです。ほかの音は画面のキー表示を参照してください。スペースキーを押している間はサステインが有効になります。

## ローカルで開く

`index.html` をブラウザで開いてください。ビルドやパッケージのインストールは不要です。

## GitHub Pages

`main` ブランチのルートから公開します。`index.html` と `piano.js` を更新して `main` にプッシュすると、サイトが再公開されます。

音は実際の楽器の録音ではなく、Web Audio APIによる合成音です。
